                    LinkVault v1.0
         Хранилище ссылок с визуальными заметками
═══════════════════════════════════════════════════════════

LinkVault — это браузерное приложение для удобного хранения
ссылок, описаний и скриншотов. Все данные сохраняются 
локально в вашем браузере и не отправляются в интернет.

📌 ЗАПУСК ПРОГРАММЫ
   Просто дважды кликните по файлу LinkVault.html. 
   Программа откроется в вашем браузере по умолчанию.
   
   💡 Совет: Чтобы запускать программу в один клик, 
   нажмите правой кнопкой мыши на файл LinkVault.html 
   и выберите "Закрепить на панели задач". 
   Тогда иконка LinkVault всегда будет внизу экрана!

───────────────────────────────────────────────────────────
                    НАВИГАЦИЯ
───────────────────────────────────────────────────────────

• ВКЛАДКИ (СТРАНИЦЫ/КАТЕГОРИИ)
  Сверху под заголовком находятся вкладки — это ваши 
  страницы-категории (например: "Нейросети", "Учёба", "Видео").
  
  • Переключение: кликните на нужную вкладку.
  • Переименование: дважды кликните на название вкладки, 
    введите новое имя. Нажмите Enter или кликните в 
    другое место для сохранения.
  • Удаление: нажмите на крестик (×) рядом с названием.
    ⚠️ Все данные страницы будут удалены безвозвратно!
  • Новая страница: нажмите кнопку "+" справа от 
    последней вкладки.

───────────────────────────────────────────────────────────
                    РАБОТА СО СТРОКАМИ
───────────────────────────────────────────────────────────

Каждая строка содержит: номер, ссылку, скриншот и описание.

• ДОБАВЛЕНИЕ НОВОЙ СТРОКИ
  Новая пустая строка появляется автоматически, как только
  вы заполняете ссылку или описание в последней строке.

• УДАЛЕНИЕ СТРОКИ
  Нажмите ПРАВОЙ кнопкой мыши на НОМЕР строки (первый 
  столбец с цифрой). Появится меню "Удалить строку".
  ⚠️ Вместе со строкой удаляются ссылка, описание и 
  скриншот — без возможности восстановления!

• ПЕРЕМЕЩЕНИЕ СТРОК (Drag & Drop)
  Зажмите левую кнопку мыши на любой строке и перетащите 
  её на нужное место. Остальные строки автоматически 
  сдвинутся. Порядок сохраняется.

• ПОДСВЕТКА ДУБЛИКАТОВ
  Если вы вставите одинаковую ссылку дважды, обе строки 
  автоматически подсветятся ЖЁЛТЫМ цветом с оранжевой 
  полосой слева. Это помогает быстро найти повторы.

───────────────────────────────────────────────────────────
                    ЗАПОЛНЕНИЕ ЯЧЕЕК
───────────────────────────────────────────────────────────

• ССЫЛКА (второй столбец)
  1. Кликните в ячейку.
  2. Вставьте ссылку через Ctrl+V или Правая кнопка → Вставить.
  3. Кликните в любое другое место — ссылка автоматически
     станет синей и кликабельной.
  4. Если вы забыли http:// или https:// — программа 
     добавит их сама.
  5. При наведении мыши на длинную ссылку появится 
     всплывающая подсказка с полным текстом.

• СКРИНШОТ (третий столбец)
  1. Перейдите по ссылке и сделайте скриншот 
     (Win + Shift + S в Windows).
  2. Вернитесь в LinkVault, кликните в ячейку "Скриншот".
  3. Нажмите Ctrl+V или Правая кнопка → Вставить.
  4. Скриншот мгновенно сохранится.
  5. Двойной клик по скриншоту — открыть на весь экран.
  6. Кнопка ✕ в правом верхнем углу скриншота — удалить.

• ОПИСАНИЕ (четвёртый столбец)
  1. Кликните в ячейку и введите текст.
  2. Кликните в другое место для сохранения.
  3. При наведении мыши на длинное описание появится 
     всплывающее окно с полным текстом и прокруткой.

───────────────────────────────────────────────────────────
               СОХРАНЕНИЕ И РЕЗЕРВНЫЕ КОПИИ
───────────────────────────────────────────────────────────

⚠️ ВАЖНО: Все данные хранятся ВНУТРИ браузера (IndexedDB).
При очистке данных браузера или переустановке Windows 
данные LinkVault будут УДАЛЕНЫ!

• КНОПКА "СОХРАНИТЬ" (правый верхний угол)
  Создаёт резервную копию всех ваших данных в файл 
  LinkVault_backup.json. При повторном нажатии файл 
  перезаписывается. Сохраняйте периодически!

• КНОПКА "ЗАГРУЗИТЬ"
  Восстанавливает данные из ранее сохранённого файла 
  backup. Текущие данные будут заменены.

───────────────────────────────────────────────────────────
                    СОВЕТЫ
───────────────────────────────────────────────────────────

• Используйте разные вкладки для разных тематик.
• Регулярно делайте резервные копии через кнопку 
  "Сохранить".
• Файл backup можно перенести на другой компьютер и 
  загрузить там через кнопку "Загрузить".
• Для быстрого доступа закрепите ярлык LinkVault на 
  панели задач Windows.

───────────────────────────────────────────────────────────
              ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ
───────────────────────────────────────────────────────────

• Формат хранения: IndexedDB (встроенная база браузера)
• Формат резервной копии: JSON
• Скриншоты хранятся в формате Base64 внутри базы
• Работает в: Chrome, Edge, Яндекс.Браузер, Opera
• Не требует установки и интернета
